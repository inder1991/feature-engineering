Experience decisions

This panel explains the prototype; it is not part of the production screen.

1
Search and exploration are separate tasks

The global List/Graph toggle is removed. A user chooses an asset, then opens a dedicated, shareable explorer.

2
Business meaning precedes implementation detail

“Customer Number” is primary. The physical reference remains visible as supporting evidence.

3
Capability is the narrative

The inspector states safe roles, prohibited roles, recommendations and the exact condition blocking execution.

4
Recommendations are not registered lineage

Feature opportunities use a separate visual treatment and open the existing Recommended Features page.

5
Trust has independent axes

Match strength, human review and execution validation are not collapsed into a misleading “governed” badge.

6
One inspector, one selected object

Selecting a node or relationship replaces the inspector content. No drawer is stacked over a second selected-asset panel.

7
Laptop widths do not clip content

Below 1050px, controls become a horizontal toolbar and the inspector moves below the canvas.
