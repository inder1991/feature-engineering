Search-page decisions

This panel explains the artifact and is not part of the production UI.

1
Business meaning leads each result

Business Date and Customer Number are primary; physical references remain visible but secondary.

2
No global Graph toggle

A graph needs an explicit anchor. “Explore relationships” is attached to each selected result and should open a dedicated explorer.

3
Four equal actions become one hierarchy

Open asset is primary, Explore relationships is secondary, and recommendations, impact and copy live in the overflow menu.

4
Search shows capability, not every metadata field

Each row gives one or two useful roles, unresolved checks and a Recommended Features entry point. Full enrichment belongs on the asset page.

5
Filters use user language

Data role replaces scattered Grain/As-of flags. “Not classified” remains available but no longer dominates every filter group.

6
Trust is visible without noise

Source-backed facts and the catalog projection state are disclosed; “unknown” values are omitted.

7
Responsive density is intentional

The navigation collapses at laptop width, capability rows move below the asset, and facets become a horizontal filter tray on narrow screens.
