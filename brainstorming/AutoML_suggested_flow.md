# Agentic AutoML & Feature Store Integration Specification## 1. System Architecture & Flow

[User Hypothesis] ──> [Feature Generation Agent] ──> [Kedro Pipeline on Hadoop]
│
(Saves Offline Features)
│
▼
[Tool UI Dashboard] <── (Rich Summary + JSON) ── [AutoML Critic/Reporter Agent]
▲
(Feeds Metrics & Plots)
│
[AutoML Compute Engine]


### Architectural Steps
1. **Hypothesis Ingestion:** User inputs a business theory via NLP chat.
2. **Feature Engineering:** Feature Generation Agent compiles a Kedro pipeline and deploys it to the Hadoop cluster via PySpark/Trino.
3. **AutoML Trigger:** Upon Kedro pipeline success, an asynchronous webhook alerts the AutoML Microservice with the destination table path.
4. **Model Search & Metric Gathering:** The engine trains models, scores metrics (AUC, F1, Precision, Recall), and computes SHAP matrix arrays.
5. **Agentic Interpretation:** The AutoML Critic/Reporter Agent interprets raw statistics alongside the original hypothesis text.
6. **UI Population:** The Tool backend persists structured metadata, instantly updating the React/Tailwind frontend interface.

## 3. LLM Critic Prompt Strategies

### System Prompt Blueprint
```text
You are an expert Data Science Critic Agent. Your job is to analyze the raw output of an AutoML training run and map the mathematical results back to the user's business hypothesis.

Provide your final response as a clean, scannable Markdown summary containing exactly these three headers:
### 🎯 Hypothesis Validation
### 📊 Model Performance Summary
### 💡 Recommended Feature Next Steps
```

### User Prompt Ingestion Pattern
```text
User Hypothesis: {{user_hypothesis}}

AutoML Results:
- Best Model Selected: {{best_model.algorithm}}
- F1-Score: {{evaluation_metrics.f1_score}}

- Recall: {{evaluation_metrics.recall}}
- ROC-AUC: {{evaluation_metrics.auc_roc}}

{{#each feature_importance}}
- `{{this.feature_name}}` (SHAP: {{this.shap_value}})
{{/each}}
```
